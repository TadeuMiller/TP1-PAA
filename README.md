# Labirinto com Chaves e Baú

Projeto desenvolvido em **C** para a disciplina de **Projeto e Análise de Algoritmos**.

O programa utiliza **backtracking** para encontrar um caminho em um labirinto, partindo da posição inicial, coletando todas as chaves e chegando ao baú.

O mapa é lido de um arquivo de texto. Os movimentos são permitidos nas quatro direções, respeitando as paredes e sem repetir salas no mesmo caminho.

Como resultado, o programa apresenta um caminho válido ou informa que não existe solução. O projeto também inclui testes para validar os caminhos e registrar as medidas de recursão.
